These files are SDL's Java glue, copied unchanged from SDL 3.4.20
(`SDL/android-project/app/src/main/java/org/libsdl/app` in the `sdl3-src`
crate that `sdl3-sys` 0.7.3+SDL-3.4.20 builds from). They must match the SDL
compiled into libmain.so: when the `sdl3-sys` version changes, copy them again
from the new `sdl3-src`.
